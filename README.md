# FlexMind AI ECU

### AI-Based Multi-Objective ECU Calibration for Dual-Fuel Internal Combustion Engines

An interactive automotive AI platform demonstrating how Machine Learning can be used for adaptive Engine Control Unit (ECU) calibration in flex-fuel and dual-fuel internal combustion engines.

Built as a research-driven visualization and simulation platform accompanying the paper:

**"AI-Based Multi-Objective ECU Calibration for Dual-Fuel Internal Combustion Engines Using Surrogate Machine Learning Models"**

---

## Overview

Traditional ECUs rely on static calibration maps generated through extensive dynamometer testing.

As fuel blends evolve from E10 to E20 and potentially E30, static lookup tables become increasingly difficult to maintain and optimize.

FlexMind explores a future where:

* Live engine feedback
* Surrogate Machine Learning models
* Multi-objective optimization

work together to create adaptive ECU calibration systems.

## Machine Learning Concepts Used

### Surrogate Modelling

Random Forest Regression models are used as surrogate models to approximate complex engine behavior.

Predicted Outputs:

* BSFC (Brake Specific Fuel Consumption)
* NOx Emissions

### Multi-Objective Optimization

Optimization objective:

J = w₁ × BSFC + w₂ × NOx

The platform demonstrates the trade-off between:

* Fuel Efficiency
* Emissions

using Pareto-based optimization concepts.
